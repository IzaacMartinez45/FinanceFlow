# FinanceFlow Dashboard

FinanceFlow is a static web application prototype designed to simulate a personal finance dashboard. This project demonstrates the front-end structure of a future analytics application using HTML, CSS, and JavaScript.

## Features
- Multi-page website (Home, Data Visualization, About)
- Simulated CRUD operations (Create, Read, Update, Delete)
- Interactive charts using Chart.js
- Responsive design for different devices
- Logical data model for finance tracking

## Purpose
This project was created as part of ISM 6225 to establish the look and feel of a final application before adding backend functionality and API integration.

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js

## Future Improvements
- API integration for real financial data
- Dynamic CRUD functionality
- User authentication system
